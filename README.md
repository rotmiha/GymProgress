# GymProgress

GymProgress je zasnova spletne aplikacije za načrtovanje treningov in
spremljanje napredka. Namenjena je rekreativcem, ki trenirajo samostojno,
in osebnim trenerjem, ki pripravljajo programe za svoje stranke.

## Predvidene funkcionalnosti

- Sestavljanje programov iz vaj, ciljnih serij in ponovitev.
- Povezovanje trenerjev in strank s potrditvijo povabila ter dodeljevanje programov.
- Beleženje opravljenih serij, ponovitev in obremenitev.
- Izračun skupnega volumna in zaznavanje osebnih rekordov ob zaključku treninga.

## Tehnološki sklad

- **Frontend:** React, TypeScript, Vite in Tailwind CSS.
- **Backend:** Node.js, Express in TypeScript z REST API-jem.
- **Podatki in prijava:** gostovani Supabase PostgreSQL in Supabase Auth.
